# Domiary — карта экранов v1

**Статус:** черновик для утверждения Игорем
**Основа:** PRD §18, §19, §35, §44; ARCHITECTURE §23; ADR-003, ADR-008

Документ описывает, какие экраны есть в v1, как между ними переходить и сколько нажатий занимают основные действия. Тексты интерфейса уточняет словарь `docs/GLOSSARY.md` (T-010).

---

## 1. Принципы

1. Главный экран отвечает на вопрос «что требует внимания сейчас», а не показывает каталог.
2. Любое основное действие — максимум 3 нажатия от главного экрана (PRD §35).
3. Создание — минимум полей: сначала название (и фото), подробности потом.
4. Ни одного слова из 1С в интерфейсе: «справочник», «документ», «провести», «реквизит» (PRD §44).
5. Один экран — одна задача. Длинные карточки делятся на вкладки.

## 2. Навигация

Пять разделов. В 1С это подсистемы верхнего уровня; на телефоне они показываются в меню разделов.

```text
┌──────────────────────────────────────────┐
│ Главная │ Вещи │ Задачи │ Финансы │ Ещё  │
└──────────────────────────────────────────┘
```

| Раздел | Что внутри | Вопрос PRD |
|---|---|---|
| Главная | требует внимания, ближайшее, недавняя история | что нужно сделать? |
| Вещи | дома и места, вещи, поиск | что у меня есть? |
| Задачи | сегодня, скоро, обслуживание, выполненные | что нужно сделать? |
| Финансы | платежи, накопления, долги, планируемые покупки | какие обязательства и ресурсы? |
| Ещё | счётчики, документы, история, настройки, резервная копия и выгрузка | что произошло? |

**Глобальная кнопка «+»** на главной и в списках открывает меню быстрого добавления: вещь, задача, показания, платёж, пополнение.

## 3. Экраны

### 3.1. Главная

```text
┌──────────────────────────────────┐
│ Дом на Лесной ▾            [ + ] │  ← выбор дома, если их несколько
├──────────────────────────────────┤
│ Требует внимания                 │
│ ● Просрочено                     │
│   ТО газового котла    5 дн. назад│
│ ● Через 4 дня                    │
│   Замена фильтра воды     [Готово]│
│ ● Через 12 дней                  │
│   Передать показания   [Ввести]  │
│ ● Через 22 дня                   │
│   Гарантия Bosch заканчивается   │
├──────────────────────────────────┤
│ Платежи в этом месяце   3 из 6 ✓ │
│ Отпуск            58% ▓▓▓▓▓░░░░  │
├──────────────────────────────────┤
│ Недавно                          │
│ ✓ Очистка кофемашины      вчера  │
│ + Kärcher K5         32 990 ₽    │
└──────────────────────────────────┘
```

- Кнопка в строке выполняет действие сразу: «Готово» отмечает задачу или обслуживание, «Ввести» открывает ввод показаний.
- Нажатие на строку открывает объект.
- Пустое состояние: три шага онбординга (раздел 4).

### 3.2. Вещи

```text
┌──────────────────────────────────┐
│ 🔍 Найти вещь, место, документ   │
├──────────────────────────────────┤
│ Дом на Лесной ▾  │ Все места ▾   │
├──────────────────────────────────┤
│ [фото] Котёл Baxi Eco     Котельная│
│        гарантия до 03.2027       │
│ [фото] Фильтр Аквафор     Кухня  │
│        ТО через 4 дня            │
│ [ — ]  Дрель Makita       Гараж  │
└──────────────────────────────────┘
```

- Под названием одна строка о самом важном: ближайшее обслуживание, или гарантия, или ничего.
- Поиск — глобальный (PRD §20): вещи, места, документы, задачи.
- «Места» открывают дерево: дом → комната → шкаф → полка.

### 3.3. Карточка вещи

```text
┌──────────────────────────────────┐
│ ← Котёл Baxi Eco          [ ⋮ ]  │
│ ┌──────────────┐                 │
│ │    фото      │  Котельная      │
│ └──────────────┘  Используется   │
├──────────────────────────────────┤
│ Обзор │ Обслуживание │ История │ Документы │
├──────────────────────────────────┤
│ Куплен     12.03.2025  48 500 ₽  │
│ Гарантия   до 12.03.2027  ✓      │
│ Модель     Eco Nova 24F          │
│ Серийный № 1234-5678             │
│ Заметка    …                     │
└──────────────────────────────────┘
```

- Меню «⋮»: переместить, изменить статус, добавить документ, удалить.
- «Обслуживание»: правила и ближайшие сроки, кнопка «Выполнено».
- «История»: хроника с отбором по этой вещи (ADR-003).
- «Документы»: вложения вещи, добавление фото или файла.

### 3.4. Быстрое добавление вещи

```text
┌──────────────────────────────────┐
│ ← Новая вещь          [Сохранить]│
├──────────────────────────────────┤
│ [ 📷 Фото ]                      │
│ Название   ____________________  │
│ Где        Кухня ▾  (последнее)  │
│                                  │
│ ▸ Подробнее: цена, дата, гарантия│
└──────────────────────────────────┘
```

- Обязательно только название. Место подставляется последнее использованное.
- «Подробнее» раскрывает остальные поля на том же экране.

### 3.5. Задачи

```text
┌──────────────────────────────────┐
│ Сегодня │ Скоро │ Обслуживание │ Готово │
├──────────────────────────────────┤
│ ○ Заменить фильтр воды    сегодня│
│   Фильтр Аквафор · каждые 6 мес. │
│ ○ Оплатить страховку      завтра │
│ ○ Проверить датчик дыма   пт     │
└──────────────────────────────────┘
```

- Круг слева отмечает выполнение одним нажатием. Для повторяющейся задачи срок сразу переносится, внизу появляется «Отменить».
- Быстрое создание: название, срок, «повторять» (каждые N дней / недель / месяцев / лет), связанная вещь — необязательно.

### 3.6. Выполнение обслуживания

```text
┌──────────────────────────────────┐
│ ← Замена картриджа        [Готово]│
│   Фильтр Аквафор                 │
├──────────────────────────────────┤
│ Дата        сегодня ▾            │
│ Стоимость   ______ ₽ (необяз.)   │
│ Кто делал   ______   (необяз.)   │
│ Фото / чек  [ + ]                │
│ Заметка     ______               │
├──────────────────────────────────┤
│ Следующий раз: 02.04.2027        │
└──────────────────────────────────┘
```

Из строки «Готово» на главной обслуживание отмечается сразу с сегодняшней датой, без этого экрана. Экран открывается, если нужно указать стоимость или фото.

### 3.7. Ввод показаний

```text
┌──────────────────────────────────┐
│ ← Электричество           [Готово]│
├──────────────────────────────────┤
│ День     _______  (было 12 340)  │
│ Ночь     _______  (было  4 210)  │
│ Дата     сегодня ▾               │
├──────────────────────────────────┤
│ Расход: день +215, ночь +98      │
└──────────────────────────────────┘
```

Поле сразу в фокусе с цифровой клавиатурой. Предыдущее значение видно рядом.

### 3.8. Финансы

```text
┌──────────────────────────────────┐
│ Платежи │ Накопления │ Долги │ Покупки │
├──────────────────────────────────┤
│ Октябрь                          │
│ ✓ Интернет         900 ₽   01.10 │
│ ○ Коммуналка     6 400 ₽   10.10 │
│ ○ Страховка     12 000 ₽   15.10 │
└──────────────────────────────────┘
```

- Платёж отмечается оплаченным одним нажатием, сумму можно поправить.
- Накопления: цель, прогресс, кнопка «Пополнить».
- Долги: две группы, «мне должны» и «я должен», остаток и срок.
- Счета с ручным остатком — в «Ещё» → «Счета», они вторичны (PRD §13.1).

### 3.9. Ещё

```text
┌──────────────────────────────────┐
│ Счётчики                       › │
│ Документы                      › │
│ История                        › │
│ Счета                          › │
│ Дома и места                   › │
├──────────────────────────────────┤
│ Резервная копия и выгрузка     › │
│ Настройки                      › │
│ О приложении                   › │
└──────────────────────────────────┘
```

- «История» — общая хроника с отбором по дому, типу события и периоду (PRD §19).
- «Резервная копия»: создать копию, восстановить (с подтверждением и предупреждением), выгрузить данные в JSON или CSV.

## 4. Первый запуск

```text
1. «Как называется ваш дом?»  [Квартира ▾] [Название] → Далее
2. «Добавьте первую вещь»      [📷] [Название] → Далее   (можно пропустить)
3. «Что нужно обслуживать?»    шаблон: «заменить …  каждые 6 мес.» → Готово
4. Главная: первая строка в «Требует внимания»
```

Цель — первая польза меньше чем за 2 минуты (PRD §35).

## 5. Основные действия

| Действие | Путь | Нажатий |
|---|---|---|
| Добавить вещь | «+» → Вещь → название → Сохранить | 3 + ввод |
| Отметить обслуживание | Главная → «Готово» в строке | 1 |
| Выполнить задачу | Задачи → круг | 2 |
| Ввести показания | Главная → «Ввести» → значение → Готово | 2 + ввод |
| Отметить платёж | Финансы → круг у платежа | 2 |
| Пополнить накопление | Финансы → Накопления → «Пополнить» → сумма | 3 + ввод |
| Найти вещь | Вещи → поиск | 1 + ввод |

## 6. Решения для Игоря

1. **Пять разделов или четыре.** Можно убрать «Финансы» в «Ещё», если финансовый модуль окажется вторичным. Рекомендация: оставить пять, финансы — четверть вопросов продукта.
2. **Выбор дома.** Переключатель вверху главной и списков (как в макете) или раздел «Дома» внутри «Вещей». Рекомендация: переключатель, он скрыт, если дом один.
3. **Отмена выполнения.** Короткая плашка «Отменить» после отметки (рекомендация) или подтверждение перед отметкой (лишнее нажатие).
4. **Шаблоны обслуживания в онбординге (шаг 3).** В MVP шаблонов нет (PRD §28). Предлагаю 5–7 текстовых подсказок без отдельного справочника шаблонов.

## 7. Что проверить в 1С

Карта нарисована «как должно быть». Перед разработкой срезов Claude проверит на мобильной платформе 8.5:

- кнопки действий внутри строк списка (главная, задачи);
- плашку «Отменить» без модальных окон;
- вкладки внутри карточки на узком экране;
- глобальную кнопку «+» в командной панели.

Где платформа не позволяет, выбирается ближайший вариант, и карта обновляется.
